# FinnBlu logo files

Made from the master logo, following *FinnBlu Logo Guidelines* (24 Oct 2026).
Always place these files; never retype the wordmark or redraw the symbol.

| File | Use |
|---|---|
| `finnblu-lockup-primary.svg` / `@1x @2x @3x.png` | Default: on white or light backgrounds |
| `finnblu-lockup-reversed.svg` / `.png` | On Midnight, navy or dark photos |
| `finnblu-lockup-navy`, `finnblu-lockup-white` | One-colour (stamps, embossing, receipt printers only) |
| `finnblu-symbol-*.svg` / `-512.png` | Symbol alone: avatars, small spaces |
| `finnblu-appicon-light-512.png`, `finnblu-appicon-dark-512.png` | App icon on white / on Midnight |
| `finnblu-avatar-800.png` | Facebook, WhatsApp, YouTube profile picture |
| `finnblu-og-1200x630.png` | Link preview image (og:image) |
| `finnblu-favicon-16/32/48.png` | Favicons (the site also uses `/favicon.svg`) |

Colours: Navy `#0E2B49`, Steel Blue `#1D558E`, FinnBlu Blue `#2476CF`, Midnight `#070D19`,
Sky `#1DB7F3`, Ice `#E1F1FE` (dark mode only), White `#FFFFFF`.

Fonts: Poppins (headings, buttons), Inter (body), Hind Siliguri (Bangla).

The wordmark was traced from the supplied logo, so these files are vectors, but they are not the
designer's original. If the original vector file turns up, replace these with exports from it.
